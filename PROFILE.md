# Sarj AI Developer API

Voice and chat AI agent platform (Arabic + English, KSA/MENA-focused). The public developer API is scoped to outbound voice calls: place a call and retrieve its status, recording, transcript, and post-call report. Exposes a REST API with a live OpenAPI 3.1 contract, a hosted MCP server, an llms.txt, and an official Python SDK.

## APIs

- **Sarj Voice API** — REST API for placing outbound voice calls and retrieving call status, signed recording URL, transcript, and async post-call report. Also exposes a hosted MCP server with createCall/getCall tools. (`https://platform-api.sarj.ai/api/v1`)

> REST API uses HTTP Bearer token auth (ApiKeyAuth); keys generated at platform.sarj.ai/api-keys. Hosted MCP server at https://platform-api.sarj.ai/api/v1/mcp (HTTP transport, OAuth/browser sign-in flow) exposes createCall and getCall tools 1:1 with the REST endpoints. OpenAPI is 3.1.0, Apache-2.0 licensed; an internal spec is also listed at /api-reference/openapi-internal.json. Official Python SDK: pip install sarj-platform-sdk (https://pypi.org/project/sarj-platform-sdk/). Webhooks (call-completed) documented in prose only — no AsyncAPI file. No GraphQL or Postman collection found. No published agent skills. No public pricing; access is account-gated. Note the correct API base URL is platform-api.sarj.ai (not the docs host).
